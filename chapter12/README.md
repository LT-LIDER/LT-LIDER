# Chapter 12

**Capsule: Best practices for effective prompting**

Authors and affiliations: Ana Guerberof-Arenas (University of Groningen), Antonio Toral (Universitat d'Alacant)

Expected study time: 2 hours per activity

Language of instruction: English

## Learning Outcomes (LT-LiDER skill(s) map)

By the end of this exercise you will be able to:

- Know prompt design
- Write for a variety of audiences
- Integrate styleguide requirements into LLMs
- Extract terminology (with LLMs)
- Use LLMs to shorten/automate QA processes
- Know LLM limitations and capabilities
- Know basic Python
- Use APIs

## Scenarios 

This capsule covers three activities related to effective prompting, using examples for a variety of languages. First, you will go through a set of examples related to effective prompting in general. Second, you explore prompting examples specific to translation. Third, you will use an API to call your AI provider of choice to run these examples programmatically. 

## Related LT-LiDER Book Chapters

To complete this casule, in addition to Chapter 12, you may find  Chapter 6 (Key Concepts in Large Language Models for Translation) and Chapter 15 (Bridging the digital divide: Making Python and the Python ecosystem accessible to translators) useful.

## Activity pre-requisites

- Reading of Chapter 12
- A Google account to access Google Colab
- Basic Python programming experience (primarily for activity 3)
- An API key (and active account/credits) for your chosen AI provider (only for activity 3)

## Overview

This capsule contains two files:
- `best_practices_prompting.ipynb`: a Jupyter/Colab Python notebook containing all the code for the activities
- `best_practices_prompting_instructions.pdf`: step-ty-step instructions each section of the notebook, covering setup,  configuration, and all three activities.

### Activities:
- **Activity 1** (Notebook Section 4): covers general examples effective prompting.
- **Activity 2** (Notebook Section 5) covers effective prompting examples related to translation.
- **Activity 3** (Notebook Section 1): covers API setup and configuration so you can run the examples in Sections 4 and 5 via your chosen AI provider.

For each activity, you can either run the prompts as provided or adapt them to your needs (e.g., by modifying the input text or language pair).
